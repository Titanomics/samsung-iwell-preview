## 미리보기와 실제 운영의 차이

원장 검토와 병원 확인이 끝나기 전의 원고입니다. 공개 미리보기의 게시 상태는 운영 승인 또는 의료 내용 검토를 뜻하지 않습니다.
비만치료는 Playground DB에서도 초안이며 정적 사본에는 없습니다. 로컬 형식 시험 원고는 공개 DB에서 제거했습니다.
공지·칼럼에는 로컬 시험 콘텐츠가 남아 있습니다. 검색·로그인·글쓰기·폼 제출·관리 화면은 정적 사본에서 작동하지 않습니다.
정적 사본의 오늘 진료 안내는 수집일 **2026-11-23**(월요일 휴진)에 고정됩니다. 실제 날짜에 따른 WordPress 동작은 Playground에서 확인합니다.
Playground는 방문자 화면으로 열리며 브라우저마다 독립된 임시 사이트입니다. 처음 열 때 WordPress와 플러그인을 내려받아 정적 사본보다 느립니다.

시험 계정의 알려진 비밀번호는 내보내기 전에 임의 값의 해시로 바꾸었고 응용 프로그램 비밀번호·세션·크론 비밀값·소금값을 제거했습니다. API 키와 운영 서버는 사용하지 않았습니다.
