## 미리보기와 실제 운영의 차이

원장 검토와 병원 확인이 끝나기 전의 원고입니다. 공개 미리보기의 게시 상태는 운영 승인이나 의료 내용 검토를 뜻하지 않습니다.
원고·상담·개인정보처리방침은 운영에서는 초안으로 만들어지고, 이 미리보기에서만 관리자가 게시했습니다. 개인정보처리방침은 운영에서 시행일을 채운 뒤 게시합니다.
칼럼의 "홈페이지 정리" 날짜는 이 미리보기를 만든 날(2026-11-26)입니다. 운영에서는 운영 사이트에 들어간 날이 찍힙니다.
KBoard 플러그인은 운영 설치 절차와 같게 넣지 않았습니다(이전 미리보기에는 있었음). 워드프레스 기본 글·예시 페이지는 지웠습니다.
환자 권리·이용약관·개인정보처리방침 변경 이력 쪽은 원고가 없어 운영 설치 경로로 만들어지지 않으므로 이번 미리보기에 없습니다(이전 미리보기의 "원고 준비 중" 자리 표시 쪽은 개발용 시드가 만든 것).
다음 웹마스터도구 인증 줄은 설정 칸만 있고 값은 넣지 않았습니다(robots.txt 는 정적 사본에 없고 Playground 는 검색 차단 상태).
칼럼 10편의 정적 사본에는 공유 이미지(og:image)가 있고 Playground 에는 없습니다. Rank Math 가 칼럼을 캐시 없이 처음 볼 때만 본문 사진을 공유 이미지로 내고 캐시에는 빈 목록을 남기는 동작 때문입니다(정적 사본은 첫 보기를 긁음).
Playground DB 사본에서만 칼럼 글 11편의 guid 를 `?p=번호` 형식으로 줄였습니다(Playground 주소가 길어 255자를 넘기 때문 — 화면·주소에는 영향 없음).

정적 사본은 검색·로그인·글쓰기·폼 제출·관리 화면이 작동하지 않습니다. 오늘 진료 안내는 수집일 **2026-11-27(금)** 에 고정됩니다. 실제 날짜에 따른 WordPress 동작은 Playground 에서 확인합니다.
390 폭 화면에서 넓은 표(진료시간·비급여 등)는 표 안에서 가로로 밀어 봅니다.
Playground 는 방문자 화면으로 열리며 브라우저마다 독립된 임시 사이트입니다. 처음 열 때 WordPress·플러그인·칼럼 사진(약 49MB)을 내려받아 정적 사본보다 느립니다(2026-11-26 설치된 Chrome headless 에서 첫 화면 1440 폭 18.8~20.1초·390 폭 16.7초 — 실제 휴대폰·다른 브라우저는 재지 않음).

시험 계정은 없습니다(관리자 1·봇 2 계정, 모두 아무도 모르는 임의 비밀번호의 해시). 응용 프로그램 비밀번호·세션·크론 비밀값·소금값은 지웠고, API 키와 운영 서버는 사용하지 않았습니다.
